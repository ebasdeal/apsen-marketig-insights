# Mock API — Demand Intelligence

`db.json` é a massa de dados do protótipo `docs/Negócio/di-drivers-v2_84.html`, servida pelo json-server 0.17 (`npm run api` → `mock-api/server.mjs`, porta 3001). Cada chave de topo é um recurso REST (`GET /tipos`, `GET /tipos/tv`, `PATCH /aprovacoes/DRV-2026-034`…). `config` é um recurso singular (`GET /config`).

Os campos e valores seguem o protótipo sem tradução. Mapas indexados por chave viraram arrays, com a chave como `id`. Inventário completo das telas em `docs/prototipo/INVENTARIO.md`.

## Escopo por ciclo ativo (DSH-01, PLN-01)

- `GET /dashboard` devolve os números do **ciclo ativo**: itens do plano (prefixo do `codigo`, ex. `PLP-2026-07-001` pertence a `PLP-2026-07`), drivers do pipeline (período do driver sobreposto à janela do ciclo) e análises (campo `ciclo`). Restrições não têm ciclo e contam as ativas. Sem ciclo ativo, `cicloAtivo` é `null` e esses totais vêm zerados.
- `GET /planoItens` não filtra por ciclo no servidor: o app envia `codigo_like=^{ciclo}-` (regex do json-server). Sem ciclo ativo o app não consulta a lista.
